# Project direction

User-confirmed: the project is “התנ״ך הוויזואלי”, a growing library of maps, charts and explanations across Tanakh and related sources, including numbers and contradictions, with real quotation-backed claims. The old HTML files are examples, not a prior agreed strategy. No conversation import is required.

Proposed, not yet user-selected: a public bilingual website as the permanent home; Instagram and YouTube as initial discovery channels; TikTok as an additional experiment. Social content derives from the visual investigations.

Recommended sequence: reusable map/time, comparison and cycle templates with a shared source ledger; a bounded Azekah pilot (or five Jerusalem sites if the user prefers); Jerusalem as a growing flagship atlas; then Israel/Judah, Gibeonites, Qumran/Community Rule and textual comparisons. Treat topic references as research leads until inspected and quoted. Scope “complete Jerusalem” by declared periods and place inventory, never imply every proposed site is securely located.

Use Now/Next/Later phases and observable completion criteria rather than invented audience figures or deadlines. The user-facing detailed roadmap was delivered separately as התנך-הויזואלי-roadmap.md. Keep this reference self-contained for use when the skill is moved.
